## 3. Challenges we hit (and how they were beaten)

- **The session was pointed at an empty USB folder.** The project was found in your
  home directory; everything was audited and committed there. (Lesson recorded below.)
- **No cmake on the machine** (needed to compile llama.cpp / whisper.cpp). Installed a
  user-local cmake without sudo; documented `sudo apt install cmake` as the proper fix.
- **bindgen couldn't find `stdbool.h`** (libclang resource headers missing) — pointed
  bindgen at the GCC include directories.
- **llama.cpp and whisper.cpp both bundle ggml → duplicate symbols at link time.**
  Solved by building transcription as its own small binary (`whisper-helper`) from the
  same crate — still fully local and in-process on your machine, no server.
- **IMAP's default TLS wanted OpenSSL** — switched to pure-Rust rustls (also keeps the
  whole build openssl-free).
- **Google Calendar dropped CalDAV basic auth** — the calendar tool says so plainly and
  routes Google/Outlook users to their MCP connectors; native CalDAV covers
  Nextcloud/Fastmail/Radicale/iCloud-style providers.
- **No espeak-ng on this machine** → see below (Kokoro).
- **The previous session's "done" claims were partly false** (uncommitted syntax error,
  dead history restore, dead settings panel, unreachable Submit). Each claim was
  re-verified against the code before being trusted.

## 4. What could not be done (and exactly why)

1. **Kokoro ONNX local speech output is not enabled in this build.**
   It requires the ONNX runtime, **espeak-ng** for phonemization, and the Kokoro model
   files — espeak-ng is not installed on this machine, so a native path could not be
   built and tested end to end. Instead of shipping an untested pipeline pretending to
   work, the app reports this honestly in Connections → Local voice, and cloud TTS
   keeps working. Installing `espeak-ng` unlocks the follow-up work.
2. **A packaged release build** (`npm run tauri:build` / .deb / .AppImage) was not
   produced. The dev/test surface is verified; `whisper-helper` additionally needs one
   `externalBin`/`resources` entry in `tauri.conf.json` before bundling so the helper
   travels with the app.
3. **Interactive smoke testing** (clicking through the running GUI) was not performed
   from here — every automated layer passed, but a hands-on pass with live provider
   keys / a real MCP server is still the final acceptance step (this is the
   longstanding "22-step acceptance re-run" item in CHECKLIST.md).
4. **Hosted MCP template URLs** for services without a canonical public server URL were
   deliberately **not invented** — the app links the registries from the starter-pack
   doc instead; you paste the URL whose server you actually run.

## 5. What would make the build better (prioritized)

1. **Finish local TTS** (Kokoro ONNX behind the existing toggle) — say the word and it's
   a contained follow-up now that the voice plumbing/status/UI already exist.
2. **Bundle whisper-helper + cmake story** for release builds; add `cmake`, `clang`,
   `libclang-dev` to your machine (`sudo apt install cmake clang libclang-dev`) so
   builds don't rely on the user-local cmake this session installed.
3. **GPU offload build profile** — llama.cpp/whisper.cpp compile CPU-only today; a
   `--features cuda` profile for your NVIDIA hardware would multiply local speeds.
4. **Vector memory for the agent** (embeddings + semantic search; current memory search
   is keyword ranking, stated honestly in the UI).
5. **Contact/identity resolution layer** — a small address book (names → emails/phones)
   so "text my brother" resolves without you spelling the number every time.
6. **Per-tool default schedules** — the scheduler exists; wiring "check email every
   morning and summarize" as one click would make the companion feel alive.

## 6. Features you may have forgotten (to outclass everything else)

- **Unified inbox triage** — one view across email/calendar/SMS with agent-suggested
  actions (reply drafts, pay dates, follow-ups) and one-tap approve.
- **Call transcripts → memory** — record your side of Twilio calls (with consent),
  transcribe locally with the Whisper engine already inside, and let the agent
  remember what was agreed.
- **Creditor-workflow templates** — prebuilt multi-step playbooks (verify debt,
  request validation, negotiate, log every exchange to a case file with documents).
- **Whiteboard export/share** — render whiteboards + artifacts to PNG/PDF for emails.
- **Cost dashboard** — per-provider/per-tool spend (Fal, Twilio, API tokens) with
  monthly caps routed into the permission system.
- **Mobile companion (PWA push)** — approvals and chat replies from your phone while
  the desktop does the work.
- **Multi-agent crews** — the Conference Room already debates; a "crew mode" where 2–3
  models divide tasks (research, writing, verification) would make long jobs faster.
- **Encrypted vault export** — one-file backup of accounts, memory, and threads.
